# Trenches-Detection-Tool-for-ArcGis-Pro
TrenchML is a deep learning-based ArcGis Pro toolkit for automated trench detection from 1 m DEMs. It uses a U-Net CNN with terrain-based post-processing to extract, refine, connect, and filter trench centrelines, providing accurate and efficient GIS-based mapping of trenches, drainage channels, and linear terrain depressions.
